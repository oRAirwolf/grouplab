# Frozen definitions: the zeroing grids as printed from 2026-09-27 to 2026-09-28

These are the four zeroing sheets of grid style 2, as NOTES-FROM-PLANNING.md entries 226 and 227 drew them (0.25 mil or 0.5 MOA squares,
labels on the grid, the scale statement and a ruler above it, the aiming ring), until entries 251, 252 and 254 replaced them with design
C3 (grid style 3). Each is named by the identifier printed on the sheet, and each is still identified when a printout of it is scanned.

**They are never edited.** A sheet printed from one of them is read against it, and its identifier changes whenever its geometry does.
