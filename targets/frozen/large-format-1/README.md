# Frozen definitions: the large format sheets as printed until 2026-09-27

These are the three large format sheets as they were printed from the first build of the library until NOTES-FROM-PLANNING.md entry 243 section 1.4, answering question 62 (a), redrew them as 2 by 2 sets of Letter and A4 sheets. Each is named by the identifier printed on the sheet, and each is still identified when a printout of it is scanned.

**They are never edited.** A sheet printed from one of them is read against it. `BuiltInLibraryTests` holds each to the reference tools' body and identifier, since `LibraryBuilder.Build` still makes them as `check.py` does.
