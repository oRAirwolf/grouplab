# Contributing to GroupLab

Read [DESIGN.md](DESIGN.md) first and [docs/TARGET-SCHEMA.md](docs/TARGET-SCHEMA.md) second. The code implements those documents section by section, and it will not make sense without them.

## Building and testing

You need:

- **Windows x64.** The desktop imaging backend uses `OpenCvSharp4.runtime.win`. It must be the full runtime: the `.slim` package compiles out every ArUco export and fails only at run time.
- **The .NET 10 SDK.** Phase 0a was built with 10.0.401.
- **Python 3**, for the reference tools under `tools/`.

Build and run the tests:

```
dotnet build
dotnet test
```

Warnings are errors. Every test must pass, and none is skipped. The tests that rasterise PDFs with PDFium run serially, because PDFium is not thread-safe.

Three more checks belong in any change that touches the format, the library or the renderer:

```
dotnet run --project src/GroupLab.Cli -- library verify tools/layout/layouts.json targets
dotnet run --project src/GroupLab.Cli -- selftest
python -B tools/layout/run.py
```

- **`library verify`** rebuilds every built-in definition and requires it to match `targets/` byte for byte. It validates each one and round-trips it through GLTD-B. The expected result is 22 definitions, 0 errors, and 4 warnings: the narrow marker bands on GL-ZERO-MOA-100Y and GL-ZERO-MIL-100M.
- **`selftest`** runs conformance test 43 on every page of every built-in sheet, without a PDF engine, and prints the bull error and registration residual for each.
- **`run.py`** must end with `16 multi-bull layouts, 4 zeroing sheets, 0 failing`.

`python -B tools/gltd/check.py` prints the reference body sizes and definition identifiers. The C# encoder is tested against a fixture dumped from it.

To render a sheet:

```
dotnet run --project src/GroupLab.Cli -- render <file.gltd.json> -o <out.pdf> [--filled] [--tile <n>] [--scale <s>]
```

`out/` is ignored by git.

## Where the truth lives

**`tools/` is the authority for geometry.**

- `tools/layout` owns every coordinate in the built-in library, through `layouts.json`.
- `tools/gltd` owns the reference encoding and identifiers.

The C# code ports these; it never adjusts them. Two consequences:

- **Never hand-edit `targets/`.** Those files are generated by `grouplab library build` and checked by `grouplab library verify`.
- **When the C# code and a tool disagree, the disagreement is the finding.** Do not move either side to make them match.

**A specification disagreement is reported, not worked around.** If a document contradicts itself, contradicts a tool, or cannot be implemented as written:

1. Stop.
2. Write down what you found, with the section and the evidence.
3. Raise it.

Do not quietly pick the reading that makes the code easier.

Where the specification is silent and a choice has to be made to go on, record the choice in [docs/SPEC-ERRATA.md](docs/SPEC-ERRATA.md), quoting the question it answers. When the specification later settles the point, delete the entry and cite the section instead.

## Conventions

- **Units.** Definitions are in integer tenths of a millimetre (dmm), per rule R1. Measurement happens in floating point; only the definition is integer.
- **Comments.**
  - Every type, and every rule that is not obvious, carries a doc comment naming the document and section it implements.
  - Conformance test numbers go on the tests that cover them.
  - Explain which paragraph the code is obeying, and why. Do not narrate what clear code already says.
- **Determinism.** Rendering the same definition twice must give identical bytes (conformance test 38): no timestamps and no unordered iteration.
- **Documents.** Markdown for files in the repository, and no em dashes.
- **No pseudoscience.** Barrel harmonics, optimal barrel time, velocity nodes and accuracy nodes are not real. They must never appear in code, comments, documentation or interface text.
- **No OnTarget compatibility of any kind.** That covers their target designs, file formats and dimensions.
- **Third-party code and packages.** List them in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) in the same change that adds them.
- **Git.** Work on a branch, not `master`.
