# Calibres in GroupLab

The calibre is entered as the bullet's diameter, and nothing else. Generated by `grouplab calibres` from `src/GroupLab.Core/Marking/Calibre.cs`; do not edit it by hand, because a test fails when this file differs from what the command writes.

## 1. How to enter a calibre

Type the bullet diameter in inches, such as .308 or 0.308, or in millimetres with mm, such as 7.82 mm. A number marked in or with an inch mark is inches too. A bare number of one or more, such as 7.62, 308 or 22, is refused rather than guessed, because a calibre's name is usually not its bullet's diameter: read as millimetres, 7.62 would be 0.300 in, which no 7.62 bullet is. Names such as 300 Blackout, 6.5 Creedmoor, 30 Cal. or 9mm are refused for the same reason. Every diameter must lie between 0.1 and 1 in.

A refusal says what to type: "Enter the bullet diameter in inches, such as 0.308, or in millimetres with mm, such as 7.82 mm."

## 3. Why there are no names

Alan decided that the calibre is a diameter and nothing else (`docs/NOTES-FROM-PLANNING.md` entry 107 section 1), reversing entries 105 and 106, which read names through a table. Every defect those entries fixed came from reading a name as a diameter, and every name the table did not know still fell back to a guess. A diameter has one meaning.
